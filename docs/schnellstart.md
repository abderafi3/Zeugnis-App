# Zeugnis-App — Schnellstart für Lehrkräfte

## Erster Start

1. **Wiederherstellungsschlüssel sichern.** Beim ersten Start zeigt die App einmalig einen
   Schlüssel an. Diesen **ausdrucken oder abschreiben** und getrennt vom Gerät sicher aufbewahren
   (z. B. Tresor). Ohne ihn sind die Daten nach einem Geräte- oder Windows-Profilwechsel verloren –
   es gibt keinen anderen Zugang.
2. **Einstellungen** öffnen (Zahnrad-Symbol unten links) und Schulname, Anschrift, Schulleitung,
   Schuljahr und aktuelles Halbjahr eintragen. Alles wird automatisch gespeichert.

## Die fünf Bereiche

| Bereich | Zweck |
|---|---|
| **Start** | Übersicht mit Anzahl Klassen, Kinder, Formulare, Floskeln |
| **Klassen** | Klassen anlegen, Kinder eingeben oder aus Excel/Word/CSV/Zwischenablage importieren |
| **Zeugnisse** | Zeugnisse ausfüllen und als Word-Datei erzeugen |
| **Formulare** | Zeugnisvorlagen und ihre Felder verwalten (die 7 Standardformulare sind vorhanden) |
| **Floskeln** | Textbausteine mit Platzhaltern `[Name]`, `[er/sie]`, `[sein/ihr]` … |
| **Fehlzeiten** | Fehlstunden je Kind für das Halbjahr |

## Ein Zeugnis erstellen

1. **Klassen** → Klasse anlegen → **Kinder öffnen** → Kinder eingeben oder **Importieren**.
2. Bei Bedarf **Fehlzeiten** für die Klasse eintragen – sie werden beim Erstellen des Zeugnisses
   übernommen.
3. **Zeugnisse** → Klasse wählen → beim Kind **Öffnen**.
   - Die passende Vorlage wird automatisch vorgeschlagen (nach Jahrgang, Halbjahr und Förderstatus).
   - Freitexte füllen; mit **Floskel einfügen** Textbausteine übernehmen (Name/Pronomen werden
     automatisch für das Kind eingesetzt).
   - Noten wählen, ggf. Empfehlung/Versetzungsvermerk, Fehlstunden prüfen.
   - Farben: 🔴 Pflichtangabe fehlt, 🟠 Text zu lang, 🟢 vollständig.
4. **Zeugnis erzeugen** → Speicherort wählen → das fertige Word-Dokument öffnet sich zur Kontrolle.
5. Wenn fertig: Schalter **„Zeugnis fertiggestellt"** setzen.

## Sichern

**Einstellungen → Sicherung → „Sicherung erstellen …"** legt eine verschlüsselte Datei an.
Regelmäßig machen und getrennt vom Gerät aufbewahren.
Zum Wiederherstellen: **„Sicherung wiederherstellen …"**, danach die App neu starten und den
Wiederherstellungsschlüssel eingeben.

## Versehentlich gelöscht?

**Papierkorb** (unten links) zeigt gelöschte Klassen, Kinder und Zeugnisse.
**Wiederherstellen** holt sie zurück. Nach 30 Tagen (einstellbar) werden Einträge endgültig entfernt.
